# NAnnersVRhub 0.5.5 — A better VR modding experience on Linux

NAnnersVRhub 0.5.5 introduces a redesigned, player-first experience for discovering, configuring and managing VR mods on Linux.

## What's new

- Cleaner game library and streamlined navigation.
- Consolidated installation and update workflows.
- Automatic VR runtime and headset detection.
- Improved VR System dashboard.
- Intelligent downloaded-archive recognition.
- Saved archive scans and optional per-game download folders.
- Clearer dependency and installation status.
- Improved setup guides and controller references.
- Installed-file recognition and maintenance reviews.
- Stronger installation, backup and recovery safeguards.

## Updating from 0.5.4

Existing managed installations can update directly through Hub updates once the release is published:

**Check now → Download source ZIP → Install update → Restart Hub**

No intermediate release or manual resource copying is required in the validated upgrade workflow.

For new installations, download the custom source archive, verify it against SHA256SUMS, extract it and run `python3 install.py`. Do not use the autogenerated GitHub source archive. Close the Hub before a manual installation.

## Safety and compatibility

Existing supported installers retain their safety checks. Advanced Fatekeeper and Hogwarts automatic installation operations, managed BepInEx maintenance and newer ERVR updates remain restricted or review-only. See the [game capability matrix](RELEASE-SCOPE-0.5.5.md) for exact limits. Close the game before mod installation or restoration. Save recovery remains development-only and disabled by default.

Application rollback is available for managed installations. It restores the previous Hub version, not game mods or saves. Back up important data independently.
