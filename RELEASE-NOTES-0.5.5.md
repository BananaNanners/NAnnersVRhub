# NAnnersVRhub 0.5.5 — release candidate

Not yet published. Current stable remains 0.5.4.

## What's new
- Cleaner game library and consolidated Overview, Install / Update, Compatibility, Update and Logs workflows.
- Scan Downloads and optional per-game archive folders, retain scan selections, distinguish verified downloads from files needing review.
- Readable setup guides and controller references for nine games; runtime and headset diagnostics with clear evidence labels.
- Installation and maintenance reviews, recognition of installed dependencies, clearer backup and recovery guidance.
- Improved protection of existing UEVR profiles and injector files, plus ERVR executable-version checks.
- Backward-compatible application packaging: the exact Hogwarts baseline is retained through a normal 0.5.4 upgrade without manual copying.

## Install or update
Linux, Python 3.11+ and PySide6 required. After publication, use Hub updates → Check now → Download source ZIP → Install update → Restart Hub. For a fresh install, verify SHA256SUMS for the custom ZIP or TAR.GZ, extract it, then run python3 install.py from the extracted folder. Open ~/.local/bin/nannersvrhub. Do not use an autogenerated GitHub source archive for the managed updater.

Keep the game closed before mod installation or restoration. Read the [game capability matrix](RELEASE-SCOPE-0.5.5.md): not every tracked mod has an automatic installer. Fatekeeper paired install/repair/recovery and Hogwarts automatic profile/injector installation remain blocked. New managed BepInEx updates and ERVR 0.9.2 are review-only. Skyrim uses its external mod manager. DOOM uses its separately pinned bridge/runner. Existing guarded installers retain their checks.

## Safety and evidence
The installer manages application files separately from game data. Application rollback switches to the retained previous Hub version; it does not undo mod or save changes. Back up important data independently. Save recovery remains development-only, disabled by default. No universal game compatibility or restart/power-loss recovery guarantee is made.

The previous checkpoint passed 1,920 regression tests. Actual stable 0.5.4 updater rehearsals used simulated GitHub delivery, real candidate archive bytes, fresh installation, two-way rollback and preserved fixture data. Final versioned regression and KDE acceptance remain pending; public endpoint delivery has not been tested. See [production readiness](DEV5G-A6.6-PRODUCTION-READINESS.md).
